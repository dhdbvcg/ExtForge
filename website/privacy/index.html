隐私政策

更新日期：2026-09-27

本政策说明 Scratch 扩展编辑器会收集哪些信息、如何使用与保存它们，以及你可以怎样管理这些信息。我们的原则是：只收集让服务正常运转所必需的最少信息。

一、我们收集的信息

登录信息：当你通过 GitHub 登录时，我们会获得你的 GitHub 用户 ID、用户名、昵称、头像地址，以及主邮箱地址。这些信息来自 GitHub 的公开接口，我们不接触你的 GitHub 密码。

账号标识：为区分不同用户，我们会为你的账号生成一个内部编号（uid），并保存它与用户名的对应关系。

存档内容：仅当你主动使用「存档」「云同步」等功能时，你当前项目的扩展配置与代码才会被上传保存。

运行信息：页面加载时的必要技术信息可能被用于排查故障，不含用于广告追踪的标识符。

二、我们不收集的信息

你的 GitHub 密码、二次验证码，以及任何你未授权的仓库内容；

你未主动上传的本地作品内容；

用于广告投放或跨站行为分析的个人标识符。

三、信息如何被使用

用于识别你的身份，让你在不同设备上访问自己的存档；

用于展示你的昵称与头像，以及在你使用好友、关注等功能时建立账号之间的关联；

用于定位与修复服务故障，以及防范滥用行为。

我们不会将你的个人信息出售、出租给第三方，也不会用于与服务无关的用途。

四、信息存储在哪里

登录会话保存在你浏览器的 localStorage 中（键名 extbuilder_session），用于维持登录状态；退出登录或清除浏览器数据即可移除。

你主动上传的存档与账号资料，保存在 Cloudflare 提供的边缘存储（KV）中，用于跨设备访问。

登录过程中与 GitHub 的通信由 GitHub 处理，我们仅接收授权结果，不中转你的凭据。

五、信息的共享

除下列情形外，我们不会向第三方提供你的个人信息：

· 你主动公开的内容（如公开的个人资料页、昵称与头像）；

· 为完成登录而必须与 GitHub 交换的授权信息；

· 法律法规要求或司法机关依法定程序要求提供。

六、你的权利

你可以随时在编辑器内退出登录，清除本机保存的会话；

你可以清除浏览器中本站的数据，从而删除本机保存的全部会话与草稿；

你可以要求删除账号及云端存档 —— 通过项目仓库的 Issue 提出即可，我们会在核实身份后处理。

七、未成年人

本服务面向能够独立承担相应责任的用户。若你未满法定年龄，请在监护人指导下使用，并由监护人阅读并同意本政策。

八、政策更新

本政策可能随功能调整而更新，更新后的版本公布并同步更新顶部日期。若涉及收集范围的实质性扩大，我们会以更显著的方式提示。

对本政策有疑问，可通过项目仓库的 Issue 与我们联系。
