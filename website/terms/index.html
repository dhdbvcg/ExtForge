用户协议

更新日期：2026-09-27

欢迎使用 Scratch 扩展编辑器。本协议是你与本服务之间就使用本服务所订立的约定。请在使用前完整阅读；你开始使用（包括通过 GitHub 登录）即表示你已接受本协议全部条款。

一、服务说明

本服务提供一个可视化的 Scratch / TurboWarp 自定义扩展编辑器：你可以在浏览器中拖拽积木、编写积木实现、实时预览生成的 JavaScript 代码，并导出为可直接加载的扩展文件。

本服务按「现状」免费提供，可能随时增加、调整或下线部分功能。我们不承诺服务永不中断或绝对无错误。

二、账号与登录

本服务仅支持通过 GitHub 账号登录。登录采用 GitHub Device Flow：你需要在 GitHub 页面上确认一组用户码，本服务全程接触不到你的 GitHub 密码，也不会获取你的仓库读写权限。

我们仅获取你在 GitHub 上公开的用户 ID、用户名、昵称、头像，以及用于识别账号的主邮箱地址。

你需要妥善保管自己的 GitHub 账号。因账号被他人使用而产生的操作，视为你本人的操作。

三、你创作的内容

你在编辑器中制作的扩展、积木定义、代码与项目配置，其权利归你所有，我们不会主张任何所有权。

只有当你主动使用「存档」「同步」等功能时，相关内容才会被上传保存；不使用这些功能时，你的作品仅存放在你自己的浏览器中。

你需对自己创作和分享的内容负责，确保其不侵犯他人的著作权、商标权或其他权利。

四、使用规范

你同意不利用本服务从事下列行为：

· 上传、生成或传播违反法律法规、含有恶意代码、用于窃取他人数据的内容；

· 通过自动化手段大量注册账号、刷取资源，或干扰、破坏服务的正常运行；

· 逆向破解、绕过服务的安全机制，或未经许可抓取、批量复制服务的数据；

· 冒充他人或虚构身份，误导其他用户。

五、第三方服务

本服务依赖若干第三方：GitHub 提供账号授权；Cloudflare 提供页面托管与数据存储；TurboWarp 等兼容编辑器用于运行你导出的扩展。

这些第三方有各自的服务条款与隐私政策，你使用它们时同时受其约束。我们无法控制第三方服务的中断、变更或数据处理行为。

你导出的扩展在第三方编辑器中运行所产生的一切后果，由你自行承担。

本服务不提供任何明示或默示的担保，包括但不限于适销性、特定用途适用性与不侵权的担保。

在法律允许的最大范围内，我们对因使用或无法使用本服务而产生的任何间接、附带、特殊或后果性损失不承担责任。

请自行备份重要作品。因浏览器数据被清除、设备损坏、账号异常等原因导致的作品丢失，我们不承担恢复义务。

七、协议变更与终止

我们可能不时修订本协议，修订后的版本公布并更新顶部日期后生效。若你在协议变更后继续使用本服务，视为你接受修订内容。

若你违反本协议，我们可暂停或终止向你提供服务。你也可以随时停止使用，并通过编辑器内的退出功能结束登录状态。
