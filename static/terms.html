使用 ForgeExt（即本网站与编辑器）即表示你同意本条款。若你不接受其中任何内容，请停止使用。

一、这是什么

ForgeExt 是一个独立第三方的开源工具，用于可视化地制作 Scratch / TurboWarp 扩展。它由志愿者维护，以源代码公开的方式提供。

ForgeExt 不是 Scratch 官方产品，也与 Scratch 基金会、MIT（Scratch 官方衍生版）、TurboWarp 官方存在任何隶属、授权或背书关系。「Scratch」与「TurboWarp」是其各自权利人的商标，此处仅用于说明兼容性。

二、你的内容

你保留全部权利

你在 ForgeExt 中创建的积木定义、实现逻辑、扩展元数据，始终属于你。我们不会对其主张任何所有权。

导出物归你

你导出的 .js 扩展文件是你自己的作品。你可以自由使用、修改、分发，商业与否由你决定。

我们不存储你的项目

编辑器中的项目状态保存在你自己的浏览器本地存储（localStorage）里。我们没有服务器端的项目数据库，不会上传、备份或分析你的积木内容。

清除方式

你可以随时在浏览器设置里清除本站点数据，或在编辑器的「设置」面板中重置。这会不可逆地删除本地保存的全部项目内容。

三、账号与登录

部分功能（如协作房间、插件市场评分）需要登录。当前支持 GitHub 账号登录，我们只保存用于识别身份的最少信息（昵称、头像、账号 ID），不保存也不接触你的 GitHub 密码，OAuth 授权全程由 GitHub 完成。

你可以随时在设置中登出并清除本地账号数据。
